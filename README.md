# WordPress on AWS – Radio Station Web Server (HND Group Project)

## Project Overview
Deployed a dynamic WordPress website on AWS EC2 for Radio Lanarkshire, replacing their legacy static site. The solution provides a LAMP stack (Linux, Apache, MySQL, PHP) with a CMS for easy content updates, improved security, and cloud scalability.

**My specific contributions:**
- ✅ Testing strategy + execution (functional, performance, security)
- ✅ Wireframes and UI/UX design (Balsamiq)
- ✅ Annotated architecture diagrams (Lucidchart)
- ✅ User documentation + admin manuals
- ✅ Team coordination and progress tracking

## Lessons Learned
- Testing early saves time — we found 3 bugs before deployment
- Wireframes forced team agreement before any coding
- AWS security groups are simple but critical — triple-checked
- Team coordination in Git requires discipline (branching strategy)

## AWS Services Used (Free Tier Eligible)
- EC2 (t2.micro)
- VPC + public subnet
- Security Groups
- Elastic IP (optional)

## Future Improvements
